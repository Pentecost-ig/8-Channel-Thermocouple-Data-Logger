# 8-Channel-Thermocouple-Data-Logger
Hardware design of an 8-channel thermocouple data logger using ESP32 and MAX31856 interface modules, designed in KiCad.


Project Overview8

This project focuses on the hardware design of an 8-channel thermocouple data logger for multi-point temperature monitoring.

The design uses an ESP32-based controller and MAX31856 thermocouple interface modules to acquire temperature measurements from multiple thermocouple channels.

Key Features

8-channel thermocouple measurement architecture

ESP32-based control system

MAX31856 thermocouple interface

SPI-based sensor communication

Touchscreen display interface

Real-time clock for timestamping

microSD card interface for data storage

Hardware Design

The circuit schematic and PCB layout are developed using KiCad.

The design covers:

Microcontroller and GPIO allocation

SPI bus interfacing

Thermocouple input connections

Display and touch interface

RTC and microSD integration

Power supply considerations

Tools Used

KiCad

ESP32

MAX31856

Datasheet analysis

Project Status

Hardware design and schematic development.

Physical PCB fabrication and hardware validation have not been completed.
